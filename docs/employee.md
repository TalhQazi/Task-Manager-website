# TASKFLOW
## Employee Panel Documentation

The Employee Panel is a focused, mobile-friendly interface designed for the daily workforce, ensuring clear visibility into tasks and time tracking.

### 🏠 Personal Dashboard
- Quick view of daily assigned tasks and upcoming shifts.
- Access to urgent notifications and system broadcasts.

### ⏱️ Time Tracking
- Simple Clock-In and Clock-Out functionality.
- Review personal timesheet history for payroll verification.

### 📋 Task Execution
- View detailed instructions, locations, and attachments for assigned work.
- Real-time status updates (To Do, In Progress, Completed).
- Submit End-of-Day (EOD) updates with progress context.

### 📅 Scheduling & Communication
- View shift details and upcoming location assignments.
- Submit leave requests directly to managers.
- Direct messaging for questions and clarifications.
